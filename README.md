# Fitness Progress Tracking App

A mobile-first fitness progress tracker built with Expo and React Native. The app focuses on goal-based training, media uploads for lift tracking, and a lightweight community feed.

## Features
- Goal-based onboarding and weekly targets
- Progress uploads (image/video picker)
- Recent activity feed and community updates
- Clean, focused UI optimized for daily check-ins

## Tech Stack
- React Native
- Expo
- JavaScript

## Live Demo (Web)
https://devangi2217.github.io/fitness_progress_tracking_app/

## Run Locally
```bash
npm install
npx expo start
```

## Build Web
```bash
npx expo export --platform web
```
